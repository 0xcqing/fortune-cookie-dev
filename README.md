# Fortune Cookie Wisdom for Developers

A make.fun bounty entry: one original fortune-cookie line for a software developer. `main.ts` (TypeScript, Node 22+, zero dependencies) writes that line to `entry.txt` — `process.env.MAKEFUN_OUTPUT_DIR` if set, otherwise `/output` — creating the directory as needed and emitting exactly the line plus one trailing newline, with a built-in assert that refuses anything outside 1–120 characters. The line is a single balanced sentence about debugging, fixing, and the long tail of explaining legacy code.
